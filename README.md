# Python 爬虫实战作业

三个实战项目的完整代码与数据。

## 实战一：豆瓣电影 Top250

- 目标：爬取豆瓣电影 Top250 全部 250 部的详情数据
- 技术：requests（列表页）+ Selenium 无头浏览器（详情页）+ BeautifulSoup 解析
- 关键设计：断点续爬（每爬一部立即存盘、重跑自动跳过已完成）、超时重试、限流自动收工
- 代码：`douban_top250_full2.py`
- 数据：`douban_top250_full.csv`（250 部 × 21 个字段：名称/年份/导演/主演/类型/评分/评价人数/五星~一星占比/剧情简介等）

## 实战二：软科中国大学排名

- 目标：爬取软科 2024 中国大学排名
- 技术：F12 抓包找到背后的 JSON 接口（页面是 JS 渲染，直接请求接口绕过翻页）
- 代码：`university_ranking.py`
- 数据：`university_ranking_2024.csv`（594 所大学：排名/中英文名/省份/总分/办学层次/类型）

## 实战三：微博话题爬虫（#中国航天#）

- 目标：爬取正能量话题 #中国航天# 的博文、一级评论、二级评论
- 技术：m.weibo.cn 移动端接口（JSON），登录 Cookie 鉴权，三层翻页
- 关键设计：博文按 page 翻页、评论按 max_id 翻页、二级评论按 cid 挖取；全链路去重；IP 属地从评论 source 字段提取
- 代码：`weibo_topic.py`
- 数据：`weibo_posts.csv`（102）/ `weibo_comments.csv`（102）/ `weibo_sub_comments.csv`（22），三表通过 博文id / 父评论id 外键关联

## 数据分析与可视化

- `plot_hourly_comments.py`：生成话题每小时评论数柱状图（`每小时评论数柱状图.png`）

## MySQL 入库

- `import_to_mysql.py`：创建数据库 `crawler_data`，建 4 张表并导入全部 CSV 数据（豆瓣表 + 微博三表，含外键约束）

## 踩坑记录（部分）

1. 豆瓣对高频访问限流：约 80 个详情页/时间窗，超出后页面挂起——靠断点续爬 + 分批爬取解决
2. 微博 Cookie 有效期短（几小时）：过期返回 ok=-100，需重新从浏览器复制
3. 微博搜索翻页翻深会"绕回头"返回重复数据——全链路按 id 去重
4. 微博话题页 containerid 直接请求拿不到数据——改用综合搜索接口替代
