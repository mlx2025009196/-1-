#Python爬虫实战作业

三个实战项目的完整代码与数据。

##实战一：豆瓣电影Top250

(1)目标：爬取豆瓣电影Top250全部250部的详情数据
(2)技术：requests（列表页）+Selenium无头浏览器（详情页）+BeautifulSoup解析
(3)关键设计：断点续爬（每爬一部立即存盘以及重跑自动跳过已完成）、超时等待重试、限流自动停止
(4)代码：`douban_top250_full2.py`
(5)数据：`douban_top250_full.csv`（250部×21个字段：名称/年份/导演/主演/类型/评分/评价人数/五星~一星占比/剧情简介等）

##实战二：软科中国大学排名

(1)目标：爬取软科2024中国大学排名
(2)技术：F12抓包找到背后的JSON接口（页面是JS渲染，直接请求接口绕过翻页）
(3)代码：`university_ranking.py`
(4)数据：`university_ranking_2024.csv`（594所大学：排名/中英文名/省份/总分/办学层次/类型）

##实战三：微博话题爬虫（#中国航天#）

(1)目标：爬取正能量话题#中国航天#的博文、一级评论、二级评论
(2)技术：m.weibo.cn移动端接口（JSON），登录Cookie鉴权，三层翻页
(3)关键设计：博文按page翻页、评论按max_id翻页、二级评论按cid挖取；全链路去重；IP属地从评论source字段提取
(4)代码：`weibo_topic.py`
(5)数据：`weibo_posts.csv`（102）/`weibo_comments.csv`（102）/`weibo_sub_comments.csv`（22），三表通过博文id/父评论id外键关联

##数据分析与可视化

(1)代码：`plot_hourly_comments.py`：生成话题每小时评论数柱状图（`每小时评论数柱状图.png`）

##MySQL入库

(1)代码：`import_to_mysql.py`：创建数据库`crawler_data`，建4张表并导入全部CSV数据（豆瓣表+微博三表，含外键约束）

##报错、失败的主要原因和解决方法

(1)实战一豆瓣对高频访问限制我的IP访问：第一次是80个详情页/时间窗，超出后页面挂起，进不去了——>断点续爬+分多批爬取
(2)实战三微博Cookie有效期太短了：过期返回ok=-100，重新从浏览器复制
(3)实战三微博搜索翻页翻深会"绕回头"返回重复数据——全链路按照id去重
(4)实战四微博话题页containerid直接请求拿不到数据——改用综合搜索接口去替代
